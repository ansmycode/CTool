# 游戏会话软重置计划

> 状态：待实施
>
> 目标：游戏关闭后清理本次会话并回到可直接重新启动游戏的状态，不重启整个 CTool。

## 处理流程

```text
游戏进程退出
  → 从 plugins.js 移除 CTool 插件项并删除本次插件脚本
  → 无论文件清理是否成功，都清空主进程游戏会话
  → 通知渲染进程卸载 CheatMenu
  → 切回“游戏启动”页并保留最近游戏信息
  → 用户可以一键重新启动游戏
```

## 实施要点

1. MV/MZ 使用 `js/plugins.js` 和 `js/plugins/CTool_*.js` 注入，保留并且不改动游戏原有插件项。
2. 游戏退出时只移除 CTool 命名的插件项和脚本；启动时自动迁移旧版 `index.html` 标记注入。
3. 游戏退出清理使用 `try/finally`，文件清理失败不能阻止主进程状态和页面状态重置。
4. React 收到 `game-closed` 后卸载 CheatMenu、切回启动 Tab，但保留最近的 `gameInfo`。
5. 内嵌翻译完成后明确提示“当前游戏不会热更新，请关闭并重新启动游戏”。

## 验收

- 游戏关闭后 CTool 不重启、不残留 CheatMenu 状态，并回到启动页面。
- 最近游戏无需重新选择即可再次启动。
- 注入文件清理失败时仍能正常返回启动页面，并给出简短错误提示。
- 内嵌完成后重启游戏可以读取修改后的磁盘数据。
