# CTool UI 样式约束

## 风格关键词

**简约、紧凑、低装饰、单色强调、信息优先、桌面工具感**

## 约束规则

1. 颜色只使用白色、浅灰、中性文字色和一个主蓝色；警告、错误等状态色仅在确有语义时使用。
2. 不使用渐变，不堆叠不同颜色的装饰色块，不为普通图标单独增加彩色背景。
3. 图标只用于能提升识别效率的操作；文字已经清楚时不再附加图标。
4. 默认使用 Ant Design 常规或小尺寸控件；按钮、开关和输入框避免无意义放大。
5. 卡片只承担内容分组作用，使用细边框、小圆角和极轻或无阴影。
6. 页面留白以清晰为准，区块间距保持紧凑，同级操作尽量在一行展示。
7. 标题层级不超过三级；说明文字保持简短，不重复按钮或字段已经表达的信息。
8. 新功能沿用现有分组和网格，不为每项功能创造新的视觉样式。
9. 动效、插画、徽章和装饰性元素默认不使用，除非能明确改善状态反馈。
10. 优先保证桌面窗口中的信息密度、扫描效率和后续扩展性。
11. 主页、配置页等固定功能页面默认禁止滚动，必须在应用固定窗口内完整展示全部操作。
12. 只有表格、列表和其他大量数据页面允许内部滚动；滚动区域不得侵占底部 Footer。
